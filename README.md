# Jam — vos amis, vos défis, votre musique

Un défi dans le salon, un ami pour le valider, un jeton pour choisir la prochaine chanson. **Jam transforme votre soirée en jeu musical, chacun à son rythme.**

**[Ouvrir Jam →](https://jam-wine-mu.vercel.app/)**

Pas d’adresse e-mail à renseigner, pas d’application à acheter. Un téléphone connecté à Internet suffit. La musique reste dans votre application musicale habituelle : la personne qui la contrôle ajoute les chansons demandées. Vous pouvez aussi profiter de la playlist sans participer au jeu.

## Rejoindre une soirée

1. Ouvrez le lien d’invitation ou scannez le QR code de votre hôte. Vous pouvez aussi saisir le code dans **Rejoindre**.
2. Choisissez un pseudo et entrez dans la soirée.
3. Dans **Jouer**, conservez votre **code personnel de récupération**. Gardez-le secret : il permet de retrouver votre profil et vos jetons si vous perdez votre connexion au profil.

Le code de soirée sert à inviter vos amis. Le code personnel sert uniquement à récupérer votre propre profil.

## Gagner votre première chanson

1. Dans **Jouer**, appuyez sur **Tirer un défi**.
2. Choisissez un autre participant comme témoin et demandez son accord.
3. Attendez qu’il accepte dans **Témoigner** : c’est à ce moment que l’épreuve commence.
4. Réalisez le défi. Votre témoin confirme la réussite ou l’échec.
5. Une réussite vous donne **un jeton d’ajout**. Rendez-vous dans **Musique** pour proposer une chanson !

Le chronomètre ne décide pas du résultat. Le témoin peut valider après la fin du compte à rebours s’il a constaté la réussite dans le délai.

### Si le défi ne se passe pas comme prévu

- **Témoin indisponible :** choisissez-en un autre. Si l’épreuve avait commencé, elle recommence avec son accord. Ce remplacement ne permet pas de retenter un défi déjà déclaré raté.
- **Défi raté :** choisissez le « sacrifice liquide » prévu par l’organisateur, ou abandonnez. Il n’y a pas de deuxième tentative du même défi après un échec.
- **Sacrifice liquide :** c’est une alternative dont le contenu est choisi dans les réglages de la soirée. Elle reste indisponible tant qu’elle n’a pas été configurée. Sa réussite donne un jeton d’ajout ; après un sacrifice raté, seul l’abandon reste possible.
- **Abandon :** attendez dix minutes avant de tirer un nouveau défi.

## Demander de la musique

Dans **Musique**, écrivez la chanson et l’artiste avec vos mots. Votre demande coûte **un jeton** et arrive dans la liste de la personne qui contrôle la musique.

Vous pouvez avoir **une seule chanson en attente**. Dès que cette personne confirme **Ajouté à la file**, votre demande est terminée : vous pouvez en proposer une autre si vous avez encore un jeton. Vous n’avez pas besoin d’attendre que la chanson commence.

Si le morceau est introuvable, la personne qui contrôle la musique peut refuser la demande avant son ajout, avec un motif. Votre jeton vous est alors rendu.

### Et les skips ?

Un skip sert à demander de passer le morceau en cours. Il ne fait pas passer votre propre chanson avant les autres.

- Le bonus de skip est à **0 % au départ**. L’organisateur peut augmenter cette chance dans les réglages.
- Une réussite de défi peut donner un skip en plus du jeton d’ajout. Le sacrifice ne donne pas ce bonus.
- Vous pouvez conserver au maximum **un skip**, et une seule demande de skip peut être en attente pour toute la soirée.
- Votre jeton est réservé pendant le traitement, puis utilisé si le morceau est passé. Si le skip n’est pas effectué, il vous est rendu.

## Organiser un Jam

1. Sur l’accueil, choisissez **Créer**, puis indiquez votre pseudo et le nom de la soirée.
2. Dans **Réglages**, choisissez les défis, leur durée, l’alternative facultative et la probabilité du bonus skip.
3. Désignez la personne qui contrôle la musique. Au départ, c’est vous ; ce rôle peut aussi participer au jeu.
4. Lancez votre playlist dans votre application musicale.
5. Appuyez sur **Inviter · QR code** pour afficher le QR code, copier le code sans tirets ou partager le lien d’invitation.

### Pour la personne qui contrôle la musique

L’écran **Régie** rassemble les demandes et les réussites des joueurs. Pour une chanson :

1. Appuyez sur **Copier la demande**.
2. Retrouvez la chanson dans votre application musicale et ajoutez-la à la file.
3. Revenez dans Jam et confirmez **Ajouté à la file**. C’est terminé !

Pour un skip, vérifiez le morceau réellement en cours avant d’agir. S’il a déjà changé naturellement, annulez la demande pour rendre le jeton.

## Installer Jam et recevoir les notifications

Sur l’accueil, **Comment jouer et installer Jam** explique le jeu en trois étapes et affiche un guide iPhone/iPad ou Android. Si le navigateur propose une installation directe, le bouton **Installer Jam** apparaît. Vous pouvez toujours jouer sans installer. Le guide reste disponible avec **?** ; dans **Inviter · QR code**, **Copier un message pour les amis** prépare le lien et les explications à partager.

Dans le menu de votre navigateur, choisissez **Installer l’application** ou **Ajouter à l’écran d’accueil**. Cette option peut aussi se trouver dans **Partager**. Ouvrez ensuite Jam depuis sa nouvelle icône.

Une fois dans une soirée, appuyez sur **?**, en haut à droite, puis sur **Activer les notifications** et **Tester mes notifications**. Les notifications de Jam sont disponibles sur téléphone ; elles sont désactivées sur ordinateur.

Les réglages du téléphone peuvent retarder ou masquer une notification. Même sans notification, retrouvez vos invitations dans **Témoigner** et les demandes musicales dans **Régie**. La réception sur écran verrouillé reste à vérifier sur les appareils de votre soirée.

## Questions pratiques

**Je ferme l’application : est-ce que je perds mes jetons ?**

Non. Votre progression est conservée. Si votre profil n’est plus reconnu, utilisez **Récupérer** sur l’accueil avec le code de soirée et votre code personnel.

**Que se passe-t-il sans Internet ?**

Vous pouvez consulter les dernières informations chargées. Les actions sont bloquées jusqu’au retour de la connexion. Si une action attend confirmation, utilisez **Vérifier la dernière action**.

**Peut-on supprimer une soirée ?**

Oui. Dans **Réglages → Clore et effacer la soirée**, l’administrateur recopie le code de la soirée pour confirmer. La suppression est définitive pour tous les participants. **Quitter ce profil** vous déconnecte sans effacer la soirée.

Une soirée sans ouverture ni action pendant **six mois** est supprimée automatiquement lors du nettoyage quotidien. Si le serveur est en pause, le nettoyage reprend à sa réactivation. Pour les soirées existantes, ce délai commence lors de l’installation de cette fonctionnalité.

**Peut-on supprimer un joueur ?**

L’administrateur peut le faire dans **Réglages → Les participants**. Le profil, les jetons et les demandes de ce joueur sont supprimés. Les chansons déjà ajoutées dans votre application musicale y restent. Les épreuves dont il était témoin attendent un nouveau témoin ; un échec déjà validé reste un échec. S’il était responsable musical, l’administrateur reprend ce rôle. Le joueur peut revenir avec un profil neuf ; il ne récupère pas son ancienne progression.

**Est-ce gratuit ?**

Oui, Jam utilise un hébergement gratuit avec des quotas. Le service peut être mis en pause après une période d’inactivité : l’organisateur doit vérifier l’accès avant la soirée et contacter la personne qui gère l’hébergement si nécessaire. La connexion Internet et votre service musical restent séparés.
